# ESP32 RL Hardware-in-the-Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train a SAC pendulum swing-up policy on the Mac, run it as plain C on the Arduino Nano ESP32 (ESP32-S3), and close the loop over USB serial with a report of returns, chip-vs-Python action difference, inference time and round-trip time.

**Architecture:** Python (`rl/`) trains with Stable-Baselines3 and exports the actor to a C header. One `rl/mlp.c` is compiled both on the host (equivalence test via ctypes) and in an ESP-IDF app (`rl/firmware`) that answers fixed-size binary requests on USB-Serial/JTAG. `rl/hil.py` steps Gymnasium `Pendulum-v1` on the Mac and asks the board for each action.

**Tech Stack:** Python 3.12 (uv), gymnasium, stable-baselines3, torch, numpy, pyserial; C11; ESP-IDF release-v5.5 in Docker (`tools/idf.sh`); `uvx esptool` for flashing.

**Spec:** `docs/superpowers/specs/2026-11-16-esp32-rl-hil-design.md`

## Global Constraints

- All new code under `rl/`; no changes to `firmware/`, `sim/`, `hardware/` (Makefile, `.gitignore`, `AGENTS.md` edits allowed).
- Own venv `rl/.venv` (torch never enters `sim/.venv`).
- Firmware builds into `rl/firmware/build-esp32s3/` with `-D SDKCONFIG=build-esp32s3/sdkconfig`; commit `sdkconfig.defaults`, never `sdkconfig`.
- Policy: SB3 SAC, `net_arch=[64, 64]`, ReLU; deterministic action `tanh(mu) * 2.0`; obs `[cos th, sin th, th_dot]` unnormalized.
- Protocol (little-endian): request 14 B = `0xA5`, `seq` u8, 3 x f32; reply 10 B = `0x5A`, `seq` u8, f32 action, u32 cycles. Reply timeout 100 ms = lost.
- CPU 240 MHz; inference us = cycles / 240.
- Gates: host C vs torch max abs err < 1e-5; HIL lockstep chip vs torch max abs < 1e-4; mean chip return over 10 episodes > -250; 0 lost / out-of-order replies over 2000 steps.
- Flashing overwrites the Arduino sketch (user-approved). If download mode fails: hold B1 to GND, reset.
- Ignored: `rl/.venv/`, `rl/out/`, `rl/firmware/build-*/`, `rl/firmware/sdkconfig*` (not `.defaults`). `rl/firmware/main/policy_weights.h` is committed.

## Review Focus

1. Junk bytes on the port (ROM boot banner after reset, a half-written reply from a previous run): host must resync on `0x5A` and match `seq`, not read a fixed 10 bytes blindly. Test in Task 3.
2. A reply that never comes (board reset, unplugged): `act()` returns `None` within ~100 ms, the run counts it as lost and fails the gate instead of hanging. Test in Task 3.
3. `seq` wrap from 255 to 0 over a 2000-step run: still matches. Test in Task 3.
4. Stale `policy_weights.h` (exported from a different model than the one `hil.py` loads): the lockstep gate must catch it, so `hil.py` loads the same `rl/out/sac_pendulum.zip` that wrote the header and fails loudly if it is missing. Covered by Task 3's gate.
5. Header/C dimension mismatch: `mlp.c` uses only the `POLICY_*` defines from the header and `_Static_assert`s them, so a shape change fails to compile. Task 1.

- Produces (header, generated): `#define POLICY_OBS 3`, `POLICY_HIDDEN 64`, `POLICY_ACT 1`, `POLICY_ACTION_SCALE 2.0f`; `static const float policy_w0[64][3], policy_b0[64], policy_w1[64][64], policy_b1[64], policy_w2[1][64], policy_b2[1];` taken from `model.actor.latent_pi[0]`, `[2]` and `model.actor.mu`, printed with `%.9g`.
- Produces (C, `rl/mlp.h`): `float mlp_forward(const float obs[3]);` static buffers only, no allocation.

```python
def test_c_forward_matches_torch(tmp_path):
    model = SAC("MlpPolicy", gym.make("Pendulum-v1"), policy_kwargs=dict(net_arch=[64, 64]), seed=0)  # untrained
    export_header(model, tmp_path / "policy_weights.h")
    lib = build_mlp(tmp_path)  # cc -O2 -shared -fPIC -I{tmp_path} rl/mlp.c -o {tmp_path}/libmlp.so; ctypes, argtypes float*
    rng = np.random.default_rng(0)
    th = rng.uniform(-np.pi, np.pi, 1000); thd = rng.uniform(-8, 8, 1000)
    obs = np.stack([np.cos(th), np.sin(th), thd], 1).astype(np.float32)
    err = max(abs(c_action(lib, o) - reference_action(model, o)) for o in obs)
    assert err < 1e-5
```
