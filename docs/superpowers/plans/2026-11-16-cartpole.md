# Cart-pole (balance + swing-up) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train, flash and run a continuous cart-pole (balance and swing-up) through the existing HIL pipeline, next to the pendulum.

**Architecture:** One own Gymnasium env (`cartpole.py`, registered with a 500-step `TimeLimit`), selected with
`ENV=` in every `make` target. The C forward pass and the serial protocol become generic in `POLICY_OBS`; the
header records which env it came from, and `hil.py`/`viz.py` refuse a mismatched header.

**Tech Stack:** Python 3.12, gymnasium, SB3 SAC, torch, pyserial, matplotlib; C11 on ESP-IDF v5.5 (Docker).

**Spec:** `docs/superpowers/specs/2026-11-16-cartpole-design.md`

## Global Constraints

- Physics: m_cart 1.0 kg, m_pole 0.1 kg, half-length l 0.5 m, g 9.81, dt 0.02 s, force u in [-10, 10] N, track |x| <= 2.4 m, 500 steps.
- Obs `[x, x_dot, cos th, sin th, th_dot]`, th = 0 upright. Action space `Box(-1, 1, (1,))`, force = 10 * action.
- Reward `cos th - 0.1 * x^2 - 0.001 * u^2` (u in N); leaving the track: terminated, reward -100.
- Success: not terminated and cos th > 0.95 on each of the last 100 steps. Gate: >= 9/10 on the board, max |chip - torch| < 1e-4, 0 lost.
- Pendulum gate stays mean return > -250; README pendulum results must reproduce with `ENV=pendulum`.
- On-chip code: no dynamic allocation; `mlp.c` builds on host and target; only `main.c`/`mlp.c` at `-O2`.
- Request `0xA5, seq, POLICY_OBS x f32` (14 B pendulum, 22 B cart-pole); reply unchanged (10 B).

## Review Focus

1. Pole spinning several turns in swing-up: th grows unbounded; obs uses cos/sin so it must stay correct (no wrap needed). Test: obs after th = pi + 4*pi equals obs at th = pi.
2. `make hil ENV=cartpole_balance` with the pendulum header still in `firmware/main/`: must exit 2 with a message, not run 10 failing episodes. Test in Task 4.
3. `make hil ENV=x` with no `out/x.zip`: exit 2 naming `make train ENV=x`. Test in Task 4.
4. Unknown `ENV`: every script exits 2 listing the valid names, not a KeyError traceback. Test in Task 4.
5. A track exit on the last step (step 500): success must be false even though truncated is also near. Covered by success = not terminated (Task 4 test).

- [ ] **Step 3:** implement. Semi-implicit Euler (velocities first, then positions with the new velocities). Florian frictionless:
  ```
  temp   = (u + m_p*l*th_dot^2*sin th) / (m_c + m_p)
  th_acc = (g*sin th - cos th*temp) / (l*(4/3 - m_p*cos^2 th/(m_c + m_p)))
  x_acc  = temp - m_p*l*th_acc*cos th/(m_c + m_p)
  ```
  Reset noise from `self.np_random`. Reward uses the post-step state.
